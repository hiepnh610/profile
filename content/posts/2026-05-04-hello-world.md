Every blog starts somewhere. This is mine.

I'm **Hiep Nguyen**, a software engineer. I've been meaning to write publicly for a while — mostly to think more clearly, and partly in case what I figure out is useful to someone else.

## What I'll Write About

Mostly technical things:

- Problems I've hit while building software and how I solved them
- Architectural decisions and the trade-offs behind them
- Tools, patterns, and ideas I find worth sharing

No grand plan. Just writing about what I'm working on.

## How This Site Works

This blog is built with [Hugo](https://gohugo.io/) and hosted on GitHub Pages — no database, no server, no CMS. Posts are Markdown files committed to a git repo. Every push triggers a GitHub Actions workflow that builds and deploys the site automatically.

It's as simple as a blog can get, and that's exactly the point.
